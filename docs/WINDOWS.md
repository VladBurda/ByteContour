# ByteContour for Windows

1. Extract the entire Windows x64 ZIP to a folder you can write to.
2. Open ByteContour.exe inside the ByteContour folder. Keep the _internal directory with it.
3. Open Disk Explorer to scan a folder. The app uses its own bundled Python runtime.

The executable is unsigned. Storage records and settings are kept in your local user profile. ByteContour opens existing inventories from older installations in place when no ByteContour inventory exists. The app imports older preferences once into its ByteContour settings.

To remove the portable app, delete the extracted application folder. User data lives separately. Keep the inventory database if you want to retain scan, monitoring, recommendation, and cleanup history.
